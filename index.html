Politique de Confidentialité

1. Données collectées

Wallnkap collecte uniquement les données nécessaires au fonctionnement de l'application :

  • Données d'identification : Nom, prénom, adresse email, numéro de téléphone
  • Données de tontine : Historique des tours de tontine, contributions, groupes créés
  • Données techniques : Adresse IP, type de navigateur, système d'exploitation (pour la sécurité)

2. Données non collectées

⚠️ Important : Wallnkap ne collecte aucune donnée bancaire :

  • ❌ Aucun RIB (Relevé d'Identité Bancaire)
  • ❌ Aucun numéro de carte bancaire
  • ❌ Aucune information de compte bancaire

Les paiements d'abonnement (Basique 9,99€/mois ou Premium 19,99€/mois) sont gérés exclusivement par Apple (App Store) et Google (Play Store). Nous n'avons jamais accès à vos informations de paiement.

3. Visibilité des données

Les données de votre tontine (contributions, historique) sont visibles uniquement par :

  • Les membres de votre cercle de tontine
  • Vous-même (propriétaire des données)

Wallnkap ne partage jamais vos données avec des tiers à des fins commerciales.

4. Vos droits RGPD

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : Vous pouvez demander une copie de toutes vos données personnelles
  • Droit de rectification : Vous pouvez corriger vos données incorrectes
  • Droit à l'effacement : Vous pouvez demander la suppression de votre compte et de toutes vos données
  • Droit à la portabilité : Vous pouvez récupérer vos données dans un format structuré
  • Droit d'opposition : Vous pouvez vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à : contact@wallnkap.com

5. Suppression de votre compte

Conformément au RGPD, vous avez le droit de supprimer votre compte et toutes vos données personnelles à tout moment. Pour supprimer votre compte Wallnkap :

  1. Ouvrez l'application Wallnkap sur votre appareil
  2. Accédez à votre Profil (icône de profil en bas de l'écran)
  3. Allez dans la section "À propos"
  4. Faites défiler jusqu'en bas de la page
  5. Cliquez sur "Supprimer mon compte"
  6. Confirmez votre choix

Une fois la suppression confirmée, toutes vos données personnelles seront supprimées de nos serveurs dans un délai de 30 jours, sauf obligation légale de conservation. Cette action est irréversible.

Vous pouvez également nous contacter directement à contact@wallnkap.com pour demander la suppression de votre compte.

6. Conservation des données

Vos données sont conservées pendant toute la durée d'utilisation de l'application. En cas de suppression de compte, vos données sont supprimées dans un délai de 30 jours, sauf obligation légale de conservation.

7. Sécurité

Nous mettons en œuvre toutes les mesures techniques et organisationnelles nécessaires pour protéger vos données contre tout accès non autorisé, perte ou destruction.
